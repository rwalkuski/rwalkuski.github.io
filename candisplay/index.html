CAN Display

CAN Display is a small module that reads data from the car’s CAN bus and shows it on an external display.
Installation is simple: connect four wires (+12V, GND, CANH, CANL).

Supported platforms: see the Vehicles section

Current draw:
Sleep: ~2 mA
Operating: up to ~40 mA

Examples of displayed parameters (depending on vehicle):

  • Coolant temperature
  • Oil temperature
  • Gearbox oil temperature
  • Boost pressure
  • Engine torque
  • Automatic transmission gear
  • Battery voltage

See the Vehicles section for the exact parameter list per model.
